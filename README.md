## Overview
In this task, I worked with a survey dataset that contained several issues such as missing values, duplicates, and inconsistent formatting.  
The main goal was to clean the dataset and then generate insights that reveal patterns in respondent behaviour and preferences.

## Steps
1. **Loading the dataset**  
   - Imported the dataset into Python using pandas.  

2. **Data cleaning**  
   - Checked for missing values and handled them with imputation (median/mode) or by dropping irrelevant rows.  
   - Removed duplicate records to ensure data quality.  
   - Standardised column names and formats for consistency.  

3. **Handling categorical variables**  
   - Applied label encoding and mapping to transform categorical responses into numeric values where needed.  
   - Grouped responses logically (e.g., by education level, profession, or tool usage).  

4. **Exploratory analysis**  
   - Generated descriptive statistics to understand distributions.  
   - Grouped respondents by demographics and tool usage to highlight patterns.  

5. **Visualisation & Insights**  
   - Created bar charts and plots to show the most common behaviours and preferences.  
   - Highlighted top tools, skills, and demographic patterns from the survey.

## Outcome
The dataset was successfully cleaned and explored.  
Key insights about respondents’ behaviour were extracted and supported by visualisations.  
These results provide a clear understanding of trends in the survey data, which can guide further analysis or reporting.
